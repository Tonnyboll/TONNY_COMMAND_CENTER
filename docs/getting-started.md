# Executar localmente

Requer Node.js 20 ou superior.

```text
npm test
npm start
```

Abra `http://localhost:3030`.

Para iniciar um contexto, use uma mensagem explícita como:

> TONY, vamos iniciar um projeto sobre a homologação da API do Félix.

Mensagens comuns permanecem informais e não são persistidas. O arquivo local de estado fica em `data/tony.json` e é ignorado pelo Git.
