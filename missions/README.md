# Missões

Registrar apenas trabalhos que precisem de acompanhamento ou histórico.

```markdown
# M-AAAA-MM-DD-NN — Título

- Objetivo:
- Domínio e projeto:
- Estado: PLANEJADO | EM EXECUÇÃO | EXECUTADO | VALIDADO | FALHOU | AGUARDANDO CONFIRMAÇÃO
- Fontes e permissões:
- Ações realizadas:
- Evidências:
- Resultado:
- Pendências:
```

Não registrar dados sensíveis além do necessário. Um estado só pode ser marcado como executado ou validado com evidência correspondente.
