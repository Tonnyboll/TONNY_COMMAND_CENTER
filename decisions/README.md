# Decisões

Registrar decisões que devam sobreviver à conversa.

```markdown
# D-AAAA-MM-DD-NN — Título

- Data:
- Projeto / domínio:
- Decisão:
- Motivo:
- Evidência:
- Impacto:
- Estado: ATIVA | SUBSTITUÍDA
- Substituída por:
```

Uma decisão posterior pode substituir a anterior; preservar o histórico e apontar a substituição.
